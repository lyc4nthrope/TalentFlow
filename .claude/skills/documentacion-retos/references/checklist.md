# Checklist antes del commit

- [ ] Cada entregable y cada criterio del PDF tiene un lugar donde se demuestra (tabla del manual).
- [ ] Cada decisión tiene su por qué; cada desviación del PDF, su razón.
- [ ] Los números salen de una ejecución de hoy (conteo de pruebas, duraciones, cobertura).
- [ ] Cada comando escrito se ejecutó y hace lo que dice el documento.
- [ ] Cada ruta mencionada existe (`ls`), y cada enlace interno y ancla resuelve.
- [ ] El README raíz abre con "Retos 1 a N completados", el índice incluye el reto nuevo y el mapa de retos está al día.
- [ ] `PLAN.md`: fases en ✅, aprendizajes de cada fase y "Fuera de alcance" al día.
- [ ] Lo que no se pudo verificar está dicho de forma explícita.
- [ ] No hay contenido duplicado entre archivos: se enlaza.
- [ ] Commit `docs(retoN): …`, sin atribución a IA.
